### 👨‍💻 About Me

I'm a backend-focused engineer who thrives on crafting elegant, high-throughput systems — and on building the open-source tooling ecosystems around them.

- 🚀 **Seasoned Backend Engineer** — architecting robust server-side solutions, from scalable database schemas to high-performance APIs and microservices.
- ⚡️ **Reactive Advocate** — deeply invested in Reactive Programming, leveraging Rx (Rx.NET / RxPY) to build responsive, resilient applications.
- 🎓 **Google Certified Cloud Pro** — recognized as a **Professional Cloud Developer** by Google.
- 🧩 **Ecosystem Builder** — beyond the core tool, I build the IDE plugins and integrations around it (JetBrains, VS Code) so it fits real developer workflows.
- 🔧 **Kubernetes & Service Mesh Expert** — proficient in orchestrating complex systems and managing microservices at scale.
- 🧪 **Benchmarking & Testing Enthusiast** — I care about measuring systems under load as much as testing correctness, not just writing thorough unit tests.
- 🐧 **Linux Lover** — proud daily driver of Manjaro Linux.
- 🎮 **Gamer** — when I'm not coding, I'm probably gaming!
